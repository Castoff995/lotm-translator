КОРПУС: КИТАЙСКИЙ + АНГЛИЙСКИЙ

Эта папка — каноническая линия подготовки пары «китайский оригинал ↔ официальный английский».
Она не заменяет data/raw: raw хранит исходно извлечённые тексты, а здесь лежат только подготовленные
и, после ручной проверки, утверждённые артефакты для обучения.

Порядок для каждой главы:
01_zh_source -> 02_zh_units -> 03_en_source -> 04_en_units -> 05_zh_en_alignment

Файл считается эталоном только после ручной проверки и записи в config/gold_alignment_references.json.
