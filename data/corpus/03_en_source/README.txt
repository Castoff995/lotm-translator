03_en_source — чистый официальный английский источник.

Для каждой главы сюда попадает один UTF-8 .txt, вырезанный из официального английского EPUB.
Перед сохранением удаляются заголовок EPUB, реклама, сноски, навигация и другой не-романный мусор.

Это ещё не разбивка для выравнивания: сохраняется нормальный очищенный текст главы.
Пример имени: ch_0001_en_source.txt
