05_zh_en_alignment — группы «китайский ↔ английский».

Одна группа может содержать несколько абзацев с одной стороны и один или несколько с другой.
Группы создаются только из 02_zh_units и 04_en_units. Рядом хранятся JSON с индексами и HTML,
в котором есть полный текст для ручной проверки.

После проверки файл фиксируется как эталон в config/gold_alignment_references.json.
Пример имён: ch_0001_zh_en_alignment.json и ch_0001_zh_en_comparison.html
